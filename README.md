## 민서 님께

먼저, 직접 만드신 ParkFrame 페이지 잘 봤습니다. **완성도가 낮아서 고친 게 아닙니다.**
디자인 자체는 이미 깔끔했고, 그라디언트·필름스트립·타임라인 같은 요소를 다룰 줄 안다는 건
페이지만 봐도 충분히 전달됩니다.

문제는 다른 데 있었습니다. **이력서·자기소개서와 대조해보니 사실이 맞지 않는 곳이 여러 군데 있었고,
정작 가장 강력한 무기는 페이지에 안 들어가 있었습니다.**

포트폴리오는 "얼마나 예쁜가"가 아니라 **"얼마나 의도적으로 설계되었는가"**를 증명하는 물건입니다.
그 기준으로 다시 짰습니다.

- STEP · KBI · 아이폰 17 Pro 2편 → 유튜브 실제 제목 그대로 갤러리 배치

## ⚠️ 2. 숫자가 이력서와 맞지 않았습니다

채용담당자는 랜딩페이지와 이력서를 **반드시 대조**합니다.
하나라도 어긋나면 나머지 주장까지 함께 신뢰를 잃습니다.

| 항목 | 기존 표기 | 이력서 사실 |
|---|---|---|
| 실무 경력 | **2년 11개월** | 총 1년 3개월 / **영상 실무는 7개월** (2023.08–11 4개월 + 2024.03–05 3개월) |
| 코스믹블랙 재직 | 2023.08–2024.05 · 10개월 | 분리된 두 기간, 사이에 3개월 공백 |
| 자격증 | 전자기능사 | **전자기기기능사** |
| 희망 근무지 | 용산 · 강남 · 금천 | 용산 · 강남 · 금천 · **성북** |
| 고용 형태 | 정규직 / 프리랜서 | 정규직 / 프리랜서 / **인턴** |
| 지원 산업 | (없음) | **게임·애니메이션 > 모션그래픽 > 영상편집** |

> **"2년 11개월"을 지우면 약해 보일까 봐 걱정되실 수 있습니다. 그렇지 않습니다.**
> 2023.03 브랜뉴 아카데미 입학부터 지금까지가 **영상 커리어 3년 5개월**,
> 그중 **회사 실무가 7개월**입니다.
> 두 숫자를 나눠서 정직하게 쓰는 편이, **검증을 통과하기 때문에** 오히려 강합니다.
> 뭉뚱그린 숫자는 대조당하는 순간 무너집니다.

## 3. 정작 가장 강한 무기가 빠져 있었습니다

기존 페이지의 작업물 설명은 이런 식이었습니다.

> "색감·타이밍·전환 효과를 수차례 점검해 **완성도를 끌어올린** 작업입니다."

'완성도가 높다'는 건 본인의 자평이지 증거가 아닙니다.
그런데 **자기소개서에는 이미 훌륭한 증거가 있었습니다.**

> 클라이언트는 20분 분량을 요청했지만 디자인팀 자료만으로는 교육 내용을 설명하기 어려웠다
> → 디자인팀과 협의해 추가 자료를 확보하고 스토리보드를 재구성
> → 렌더링 중 영상 일부가 깨짐 → 오류 로그 분석 → **플러그인 충돌**을 특정 → 렌더링 환경 재세팅

이 서사가 랜딩페이지에는 **"렌더링 오류를 직접 추적해 해결했습니다"** 한 줄로 뭉개져 있었습니다.
두 시안 모두 이걸 **요청 → 문제 → 판단 → 결과** 4단으로 펼쳤습니다.

**그리고 자기소개서의 "실수와 배움" 슬라이드 — 이게 랜딩페이지에 없던 게 제일 아깝습니다.**

> 실수: 클라이언트와 소통 부족으로 작업 오류 발생
> 교훈: 중간 공유와 적극적 커뮤니케이션의 중요성 인지
> 개선: 주기적 체크리스트 도입 · 중간 시안 공유 의무화

주니어를 뽑을 때 채용담당자가 가장 알고 싶은 건 **"실패했을 때 어떻게 하는 사람인가"**입니다.
두 시안 모두 이 내용을 정식 섹션으로 올렸습니다. (시안 A: `RETAKE` / 시안 B: `솔직하게 말씀드립니다`)

## 4. 경력 공백은 숨기지 않고 먼저 씁니다

2023.12–2024.02, 2024.06–2024.11 공백은 **어차피 이력서에서 보입니다.**
숨기면 면접에서 추궁당하고, 먼저 말하면 **'자기 인식이 되는 사람'**이 됩니다.

두 시안 모두 공백을 타임라인에 그대로 표기하고, **그 기간에 무엇을 했는지**를 붙였습니다.
특히 이 두 가지는 강점으로 프레이밍했습니다.

- **코스믹블랙 재합류** — 인턴이 끝난 뒤 회사가 **다시 불렀다**는 사실
- **퇴사 후 작가님의 재의뢰** — 천재교육 스토리보드 3개월 협업

"같은 곳에서 두 번 부른 사람"은 짧은 경력을 상쇄하는 가장 강력한 레퍼런스입니다.

## 5. 두 시안은 어떻게 다른가

### 시안 A — `CUT` (편집실 다크)

**전략: 보여주고 설득한다.**

- Premiere·After Effects **타임라인 다크 UI와 렌더바 색**을 그대로 팔레트로 가져왔습니다
  (`#0B0C0E` 배경 + `#FF9E2C` 앰버 + `#3DDC97` 렌더 그린).
  기존 보라 그라디언트는 예쁘지만 '크리에이터 일반'의 클리셰라 **직군 식별력이 없었습니다.**
  색 자체가 "영상편집자"라는 신호로 기능하게 바꿨습니다.
- 상단 진행바가 **편집 타임라인의 플레이헤드**처럼 움직입니다. 스크롤이 곧 시퀀스 재생입니다.
- 섹션 라벨을 `SEQ 01 ~ SEQ 07` monospace로 잡아 편집실 메타포를 문자 레벨에서 지탱합니다.
- **첫 화면에 영상이 바로 나옵니다.** 영상편집자를 판단하는 첫 기준은 "컷이 어떻게 붙는가" 하나인데,
  기존 페이지는 한참 스크롤해야 영상이 나왔습니다.

**추천 지원처:** 게임·애니메이션 스튜디오, 모션그래픽 스튜디오, 영상 프로덕션

### 시안 B — `BRIEF` (채용 브리프)

**전략: 읽기 쉬워서 설득한다.**

- 채용담당자는 하루에 포트폴리오 수십 개를 훑습니다. 화려함에는 이미 둔감합니다.
  그래서 **화려함이 아니라 읽기 쉬움으로 경쟁**하게 만들었습니다.
- 상단에 **고정 요약 바**(투입 가능일 · 지원 직무 · 고용 형태 · 근무 희망지)가 항상 붙어 있습니다.
  스크롤 어디에 있든 판단 근거가 보입니다.
- **"채용담당자님이 궁금하실 5가지"** 섹션 — 면접에서 나올 질문에 페이지에서 먼저 답합니다.
  - 사수 없이 혼자 컷 뽑을 수 있나요?
  - 납기는 지키시나요? 사고가 나면 어떻게 하나요?
  - After Effects는 어디까지 되시나요?
  - **왜 3개월, 4개월씩만 다니셨나요?**
  - 언제부터 출근 가능한가요?
- 각 답변에 **근거 출처**(자기소개서 / 이력서 어느 항목)를 달았고,
  하단에 **이력서 대조표**를 넣어 검증이 바로 되게 했습니다.

**추천 지원처:** 일반 기업 인사팀, 교육콘텐츠·프로덕션 채용 실무자, 이력서 첨부 링크

### 어느 쪽을 쓰면 되나요?

**둘 다 쓰세요.** 지원처 유형에 따라 나눠 보내고, **어느 쪽 응답률이 높은지 기록**해보세요.

### 기술 메모

- 외부 의존성은 Pretendard 웹폰트뿐입니다. 나머지는 단일 HTML로 완결됩니다.
- 유튜브는 **썸네일 파사드** 방식입니다. 클릭 전에는 iframe을 넣지 않아 초기 로딩이 훨씬 빠릅니다.
  (기존 페이지는 iframe 5개를 동시에 로드했습니다.)
- 스크립트가 막혀도 페이지가 백지가 되지 않도록 `.js` 클래스 게이트 + 2.5초 안전망을 넣었습니다.
- 연락처가 포함돼 있어 `noindex, nofollow`를 걸었습니다. **링크를 받은 사람만 열람**하고
  검색에는 잡히지 않습니다.
- 모바일 375px까지 가로 스크롤 없이 동작하는 것을 확인했습니다.
