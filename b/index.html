"완성도를 높였습니다" 같은 말 대신, 요청 · 문제 · 판단 · 결과를 그대로 적었습니다.

CASE 01
포스코 공사현장 안전교육 영상
단독 책임 20분 분량 Premiere Pro After Effects 2023
요청

공사현장 안전교육용 20분 분량 영상. 편집부터 최종본 제출까지 담당했습니다.

문제

디자인팀이 준 자료만으로는 교육 내용을 충분히 설명할 수 없었습니다. 그대로 편집하면 "무엇을 조심해야 하는지"가 전달되지 않는 영상이 될 상황이었습니다.

판단
  • 디자인팀과 협의해 추가 자료를 확보
  • 교육 흐름 기준으로 스토리보드를 재구성
  • 중간 시안을 공유해 수정 요청을 즉시 반영
  • 렌더링 실패 → 로그 분석 → 플러그인 충돌 특정 → 렌더 환경 재세팅
결과

20분 최종본 기한 내 납품. 자료 보강과 스토리보드 재구성으로 교육 전달력을 높였고, 렌더링 사고에도 일정 지연 없이 마무리했습니다.

유튜브 공개본 「포스코이앤씨 기업 콘텐츠 영상」 · 클릭하면 재생됩니다.

CASE 02
VR 병원 소개 영상
사수 없음 미경험 포맷 1주일 완성 Premiere Pro 2023
요청

입사 첫날 PD 지시로 배정된 VR 콘텐츠 편집. 기한은 고정이었습니다.

문제

VR 편집은 한 번도 다뤄본 적 없는 포맷이었고, 물어볼 사수도 없었습니다.

판단
  • 지인·커뮤니티·유튜브로 Premiere VR 워크플로를 독학
  • 매일 진행분을 공유해 방향이 어긋날 위험을 차단
  • "막막해하기보다 부딪혀 본다"를 원칙으로
결과

1주일 만에 1차본 완성 · 기한 준수. 이후 교육 영상·숏폼 제작 속도가 함께 올라갔고, 한 달 뒤 신규 인턴 리딩 역할을 맡았습니다.

공개 링크 없음

클라이언트 납품물이라 공개 링크가 없습니다. 필요하시면 메일로 개별 공유드리겠습니다.

첫 실무 프로젝트. 입사 직후 단독으로 맡았습니다.

CASE 03
천재교육 수학 영상 스토리보드
퇴사 후 재의뢰 3개월 협업 기획 · 구성 2024
요청

퇴사 후 협업 작가님이 직접 다시 의뢰해 진행한 3개월 스토리보드 작업.

문제

스토리보드는 처음이었습니다. 편집자에서 기획자로 역할이 바뀌면서 생소한 부분이 많았습니다.

판단
  • 모르는 부분은 주저하지 않고 작가님께 질문하고 가이드를 요청
  • 실무자의 노하우를 빠르게 흡수해 이후 작업에 바로 적용
결과

3개월 완주. 편집을 넘어 콘텐츠의 흐름을 설계하는 기획 역량을 확보했습니다. 퇴사한 사람에게 다시 일을 맡기셨다는 점이 이 작업의 가장 정확한 평가라고 생각합니다.

공개 링크 없음

교육 콘텐츠 기획 산출물이라 공개 링크가 없습니다. 스토리보드 원본은 요청 시 공유드립니다.
