## 0. 핵심 원칙

디자인은 화면을 꾸미는 일이 아니라 **문제를 해결하는 과정**입니다.
이 랜딩페이지가 해결해야 할 문제는 "예쁜 페이지가 없다"가 아니라,
**"채용담당자가 3분 안에 면접을 부를 근거를 찾지 못한다"** 입니다.

## 1. 진단 — 현재 랜딩페이지의 6가지 전략적 결함

### ⚠️ 결함 1. 이력서와 숫자가 맞지 않는다 (최우선 수정)

채용담당자는 랜딩페이지와 이력서를 **반드시 대조**합니다. 불일치가 하나라도 나오면
나머지 모든 주장의 신뢰도가 함께 떨어집니다. 현재 페이지의 불일치 항목:

| 랜딩페이지 표기 | 이력서 사실 | 판정 |
|---|---|---|
| 실무 경력 **2년 11개월** | 총 경력 1년 3개월 / **영상 실무는 7개월** (코스믹블랙 2023.08~11 4개월 + 2024.03~05 3개월) | ❌ 과장 |
| 경력 타임라인 "2023.08 — 2024.05 · 실무 10개월" | 두 번의 분리된 재직 기간, 사이에 4개월 공백 | ❌ 사실 왜곡 |
| **전자기능사** | **전자기기기능사** (2019.07, 한국산업인력공단) | ❌ 자격증명 오기 |
| 희망 근무지 "용산 · 강남 · 금천" | 용산 · 강남 · 금천 · **성북** | ⚠️ 누락 |
| 고용 형태 "정규직 / 프리랜서" | 정규직 / 프리랜서 / **인턴** | ⚠️ 누락 |
| GTQ 1급 · GTQi 2급 (2026.06) | 이력서(2026.02.23 최종수정)에 미기재 | ⚠️ **본인 확인 필요** — 취득했다면 이력서를 갱신할 것 |
| 지원 직무 "영상편집 · 모션그래픽" | 직무: 영상편집자 > 영상제작 / **산업: 게임·애니메이션 > 모션그래픽 > 영상편집** | ⚠️ 타깃 산업이 페이지에 없음 |

> **전략적 판단:** "2년 11개월"을 지우면 약해 보일까 걱정할 필요 없습니다.
> 2023.03(브랜뉴 아카데미 입학)부터 지금까지가 **영상 커리어 3년 5개월**이고,
> 그중 **회사 실무가 7개월**입니다. 두 숫자를 분리해서 정직하게 제시하는 편이
> 뭉뚱그린 "2년 11개월"보다 **검증을 통과하기 때문에** 오히려 강합니다.

유튜브 oEmbed API로 5개 영상의 **실제 제목**을 조회한 결과, 원본 페이지의 매칭이 대부분 틀렸습니다.

| `V_zIek_ELSo` | **KBI** 기업 콘텐츠 영상 | "포스코 안전교육 영상" | ❌ 불일치 |

> 맞는지 최종 확인해 주셔야 합니다.

### 결함 3. 영상편집자 포트폴리오인데 첫 화면에 영상이 없다

히어로는 그라디언트 + 텍스트뿐이고, 영상은 스크롤을 한참 내려야 나옵니다.
채용담당자가 영상편집자를 판단하는 첫 기준은 **"컷이 어떻게 붙는가"** 단 하나입니다.
3초 안에 그 증거를 못 보여주면 이탈합니다.

### 결함 4. 작업물 설명이 '형용사'로 채워져 있다

> 현재: "색감·타이밍·전환 효과를 수차례 점검해 **완성도를 끌어올린** 작업입니다."

'완성도가 높다'는 건 본인의 자평이지 증거가 아닙니다. 그런데 **자기소개서에는
훌륭한 증거가 이미 있습니다.**

> 클라이언트는 20분 분량을 요청했지만 디자인팀 자료만으로는 교육 내용을 설명하기 어려웠다 →
> 디자인팀과 협의해 추가 자료를 확보하고 스토리보드를 재구성 → 교육 효과를 높였다.
> 렌더링 중 영상 일부가 깨짐 → 오류 로그 분석 → **플러그인 충돌**을 특정 → 렌더링 환경 재세팅.

이 서사가 랜딩페이지에는 "렌더링 오류를 직접 추적해 해결했습니다" 한 줄로 뭉개져 있습니다.
**Brief → Problem → Decision → Result** 4단으로 펼치는 것이 이번 개선의 핵심입니다.

### 결함 5. '누구를 위한 페이지인가'가 없다

보라색 그라디언트는 예쁘지만 근거가 없습니다. 영상편집자라는 직무 신호도,
게임·애니메이션/모션그래픽 스튜디오라는 타깃 신호도 색과 레이아웃에서 읽히지 않습니다.
"모든 사람에게 괜찮은 페이지"는 **아무도 부르지 않습니다.**

### 결함 6. 약점을 숨기려다 신뢰를 잃는다

경력 공백(2023.12~2024.02, 2024.06~2024.11)과 짧은 실무 기간은 어차피 이력서에서 보입니다.
숨기면 면접에서 추궁당하고, **먼저 말하면 '자기 인식이 되는 사람'이 됩니다.**
자기소개서의 "실수와 배움"(소통 부족 → 중간 시안 공유 의무화) 슬라이드는
랜딩페이지에 반드시 올라가야 할 **가장 강력한 자산**인데 현재 빠져 있습니다.

## 2. 프로젝트 시작 전 스스로 던져야 할 3가지 질문

### 1) 왜 만드는가? (Purpose)
- **목표:** 서류에서 걸러지지 않고 **면접 요청을 받는 것.**
- **성공 KPI (측정 가능하게):**
  - 히어로 릴 **30초 이상 시청률 60%** — 영상편집 실력을 실제로 확인시켰는가
  - **이력서 PDF 다운로드 40%** — 다음 단계로 넘어갔는가
  - **연락(메일/전화) 전환 8%** — 최종 행동이 일어났는가
  - 최종 지표: **지원 대비 면접 제안률**(현재 기준선을 먼저 기록할 것)

### 2) 누구를 위한 것인가? (Audience)
- **1순위:** 게임·애니메이션 스튜디오 / 모션그래픽 스튜디오의 **영상팀 리드·PD** (이력서 지원분야 기준)
- **2순위:** 영상 프로덕션·교육콘텐츠 제작사의 **채용 실무자**
- **그들의 심리 상태:** 하루에 포트폴리오 수십 개를 훑는다. **의심이 기본값**이고, 특히
  경력 3년 미만 지원자에게는 "혼자 굴러갈 수 있나? 사수가 붙어야 하나?"를 본다.
- **그들이 실제로 쓰는 말:**
  > "혼자 컷 뽑을 수 있어요?" · "납기 지킬 수 있나요?"
  > "AE 어디까지 되세요?" · "왜 3개월만 다녔어요?"

  → 이 4개 질문은 **페이지 안에서 먼저 답해야 합니다.** (시안 B는 아예 섹션으로 만들었습니다)

### 3) 어떤 행동을 만들 것인가? (Action)
3초: 릴 재생 → 30초: 케이스 1개 스캔 → 90초: **이력서 PDF 다운로드 또는 메일 클릭**
페이지 어디에서도 이 3단 경로에서 벗어나는 CTA는 두지 않습니다.

## 4. 의도된 디자인 결정 (Feel / Do / Decisions)

### 시안 A — "CUT" (편집실 다크)

| 항목 | 결정 | 근거 |
|---|---|---|
| **Feel** | "이 사람 실제 편집실에서 굴러본 사람이구나" — 도구적 신뢰 | 채용담당자의 의심(실무 가능?)을 첫 화면에서 해소 |
| **Do** | 히어로 릴 즉시 재생 → 케이스 스크롤 → 이력서 다운로드 | 영상 직무의 판단 기준을 3초 안에 충족 |
| **색** | 배경 `#0B0C0E` / 앰버 `#FF9E2C` / 렌더그린 `#3DDC97` | Premiere·AE **타임라인 다크 UI**와 렌더바 색. 보라 그라디언트(크리에이터 클리셰)를 버리고 **직군 코드**를 색으로 전달 |
| **타이포** | Pretendard, 히어로 -0.03em 트래킹, 라벨은 monospace 타임코드 | 타임코드/시퀀스 라벨이 편집실 메타포를 지탱 |
| **레이아웃** | 상단 고정 **플레이헤드 진행바**, 섹션 = `SEQ 01~06` | 스크롤이 곧 시퀀스 재생. 페이지 구조 자체가 직무 증명 |
| **버린 것** | 가로 드래그 필름스트립 | 모바일 스크롤 충돌 + 스캔 비용. 채용담당자는 훑기를 원함 |

### 시안 B — "BRIEF" (채용 브리프 라이트)

| 항목 | 결정 | 근거 |
|---|---|---|
| **Feel** | 침착함 · 정직함 · **검증 가능함** | 화려함으로 경쟁하는 대신 **읽기 쉬움**으로 경쟁 |
| **Do** | 상단 요약 바 30초 스캔 → 의문 해소 Q&A → 이력서 다운로드 | 바쁜 채용담당자의 실제 행동 패턴(스캔 우선) |
| **색** | 페이퍼 `#FBFAF8` / 잉크 `#16181D` / 코발트 `#2A5BD7` | 문서적 신뢰. 코발트는 링크·검증 표식에만 제한 사용해 **시선 예산**을 CTA에 집중 |
| **레이아웃** | 상단 **sticky 요약 바**(직무·투입가능일·고용형태·지역) | 스크롤 어디에 있든 핵심 조건이 항상 보임 = 판단 비용 0 |
| **차별 섹션** | "채용담당자가 궁금해하실 5가지" + "솔직하게 말씀드립니다" | 면접 전 의심을 페이지에서 미리 처리 |

## 5. 고객의 언어 활용하기

디자인 카피는 본인의 머릿속이 아니라 **채용담당자의 입**에서 가져옵니다.

| 쓰지 말 것 (지원자의 언어) | 쓸 것 (채용담당자의 언어) |
|---|---|
| "완성도를 끌어올렸습니다" | "20분 분량, 기한 내 최종본 납품" |
| "꼼꼼함이 강점입니다" | "중간 시안 3회 공유 → 수정 요청 당일 반영" |
| "끈기가 있습니다" | "렌더링 실패 → 로그 분석 → 플러그인 충돌 특정 → 환경 재세팅" |
| "올라운더 편집자를 지향합니다" | "혼자 컷 뽑고, AE로 자막·모션까지 마감까지 갑니다" |
| "빠른 습득력" | "VR 편집 미경험 → 1주일 만에 1차본 완성 (기한 준수)" |
