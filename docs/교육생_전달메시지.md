**잘한 점**

디자인 완성도는 이미 충분합니다. 그라디언트 배경, 필름스트립, 타임라인 UI를 직접 구현할 줄 안다는 게 페이지만 봐도 전달됩니다. 반응형 처리와 `prefers-reduced-motion` 대응까지 들어가 있는 건 이 수준에서 흔치 않습니다.

**그래서 이번 첨삭은 "더 예쁘게"가 아니라 "더 뽑히게"에 맞췄습니다.**

---

**🚨 1순위 — 영상과 설명이 다른 작업을 가리킵니다 (오늘 바로 조치)**

유튜브 실제 제목을 조회한 결과입니다.

- `V_zIek_ELSo` → 실제로는 **KBI 기업 콘텐츠 영상**인데 "포스코 안전교육 영상"으로 표기
- `8rwn5j6TBUQ` → 실제로는 **STEP 기업 콘텐츠 영상**인데 "VR 병원 소개 영상"으로 표기
- `Odns3Lwi-1w` → 실제로는 **포스코이앤씨 기업 콘텐츠 영상**인데 "신입 인턴 교육 영상"으로 표기

채용담당자가 클릭하면 설명과 다른 영상이 재생됩니다. **숫자 과장보다 훨씬 치명적입니다.** 기존 페이지를 지원처에 보내고 계시다면 링크부터 내려주세요.

---

**⚠️ 2순위 — 이력서와 숫자가 안 맞습니다**

- "실무 경력 2년 11개월" → 이력서 기준 **영상 실무는 7개월** (2023.08–11 + 2024.03–05)
- "전자기능사" → **전자기기기능사**
- 희망 근무지에 **성북** 누락, 고용 형태에 **인턴** 누락

채용담당자는 랜딩페이지와 이력서를 반드시 대조합니다. 하나가 어긋나면 나머지 주장까지 신뢰를 잃습니다.

**→ 개선안에서는 "영상 커리어 3년 5개월 / 회사 실무 7개월"로 분리 표기했습니다.** 뭉뚱그린 숫자보다 검증을 통과하는 숫자가 강합니다.

---

**💡 3순위 — 가장 강한 무기가 페이지에 없었습니다**

자기소개서에 있던 이 내용이 랜딩페이지에는 한 줄로만 있었습니다.

> 20분 요청 vs 자료 부족 → 디자인팀 협의해 자료 확보 → 스토리보드 재구성
> 렌더링 실패 → 오류 로그 분석 → **플러그인 충돌 특정** → 렌더 환경 재세팅

"완성도를 끌어올렸습니다"는 자평이지만, 위 서사는 **증거**입니다. 두 시안 모두 이걸 **요청 → 문제 → 판단 → 결과** 4단으로 펼쳤습니다.

그리고 자소서의 **"실수와 배움"** 슬라이드(소통 부족 → 중간 시안 공유 의무화)가 페이지에 없던 게 제일 아깝습니다. 주니어 채용에서 담당자가 가장 알고 싶은 건 **"실패했을 때 어떻게 하는 사람인가"**입니다. 정식 섹션으로 올렸습니다.

→ **일반 기업 인사팀 / 이력서 첨부용**
