## 📱 메시지 2 — 왜 고쳤는지 (여기부터 복사)

숫자도 하나 맞춰야 합니다.
"실무 경력 2년 11개월"이 이력서(영상 실무 7개월)랑 안 맞아요.

지운다고 약해지지 않습니다. **"영상 커리어 3년 5개월 / 회사 실무 7개월"로 나눠 쓰면 대조 검증을 통과하기 때문에 오히려 더 강합니다.** 뭉뚱그린 숫자는 이력서랑 맞춰보는 순간 무너지거든요.

그리고 이게 제일 아까웠어요.
자소서에 있던 **"20분 요청인데 자료가 부족 → 디자인팀 협의해서 자료 확보 → 스토리보드 재구성 / 렌더링 실패 → 로그 분석 → 플러그인 충돌 찾아냄"** 이 내용이 페이지에는 "렌더링 오류를 해결했습니다" 한 줄로만 있었습니다.

"완성도를 높였습니다"는 본인 평가지만, 위 내용은 **증거**입니다. 두 시안 모두 이걸 요청→문제→판단→결과 4단으로 펼쳐놨어요.

자소서의 **"실수와 배움"**(소통 부족 → 중간 시안 공유 의무화)도 정식 섹션으로 올렸습니다. 주니어 뽑을 때 담당자가 제일 궁금한 게 "실패하면 어떻게 하는 사람인가"라서요.

→ 일반 기업 인사팀 / 이력서 첨부용
https://vipermo15-dotcom.github.io/parkminseo-landing/b/
